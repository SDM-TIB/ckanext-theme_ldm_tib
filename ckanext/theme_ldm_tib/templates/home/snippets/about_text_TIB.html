{{ _("About the Leibniz Data Manager") }}

{{ _("The Leibniz Data Manager (LDM) is a modular research data infrastructure that enables the FAIR-compliant management and exploration of Research Digital Objects (RDOs)—such as datasets, software, documents, and scientific publications. By combining Knowledge Graphs (KGs) with Neuro-Symbolic AI, LDM supports intelligent, interoperable, and reusable data workflows across scientific domains. Key features include:") }}

  • {{ _("Metadata Representation using standard and domain-specific vocabularies (e.g., DCAT, Datacite, UMLS), ensuring semantic interoperability and alignment with FAIR principles.") }}
  • {{ _("Knowledge Graph Construction from heterogeneous data sources through a declarative data integration system (DIS), enabling structured and contextual metadata.") }}
  • {{ _("Entity Linking and Enrichment of RDOs with external KGs such as Wikidata and the Open Research Knowledge Graph (ORKG), using tools like Falcon and BioLinkedAI to automatically expand metadata.") }}
  • {{ _("On-the-Fly Metadata Updates, maintaining synchronization with evolving knowledge and newly published resources.") }}
  • {{ _("Federated Query Processing across multiple KGs, allowing users to pose natural language questions that are transformed into SPARQL and executed over LDM and ORKG.") }}
  • {{ _("Dataset Comparison and Visualization, offering tools to analyze and contrast RDOs based on shared attributes and research contexts.") }}
  • {{ _("Live Code Execution via Jupyter Notebooks, enabling reproducible scientific workflows and interactive data analysis within a secure, containerized environment.") }}
  • {{ _("Neuro-Symbolic Reasoning for both query answering and metadata expansion, combining symbolic models with LLM-based contextualization to enhance discoverability and usability of RDOs.") }}
