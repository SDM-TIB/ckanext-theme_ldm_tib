{{ _("About the Leibniz Data Manager") }}

{% trans ss=ss|safe, se=se|safe %}The {{ ss }}Leibniz Data Manager (LDM){{ se }} is a modular research data infrastructure that enables the {{ ss }}FAIR-compliant management and exploration of Research Digital Objects (RDOs){{ se }}—such as datasets, software, documents, and scientific publications. By combining {{ ss }}Knowledge Graphs (KGs){{ se }} with {{ ss }}Neuro-Symbolic AI{{ se }}, LDM supports intelligent, interoperable, and reusable data workflows across scientific domains. Key features include:{% endtrans %}

  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}Metadata Representation{{ se }} using standard and domain-specific vocabularies (e.g., DCAT, Datacite, UMLS), ensuring semantic interoperability and alignment with FAIR principles.{% endtrans %}
  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}Knowledge Graph Construction{{ se }} from heterogeneous data sources through a declarative data integration system (DIS), enabling structured and contextual metadata.{% endtrans %}
  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}Entity Linking and Enrichment{{ se }} of RDOs with external KGs such as {{ ss }}Wikidata{{ se }} and the {{ ss }}Open Research Knowledge Graph (ORKG){{ se }}, using tools like Falcon and BioLinkedAI to automatically expand metadata.{% endtrans %}
  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}On-the-Fly Metadata Updates{{ se }}, maintaining synchronization with evolving knowledge and newly published resources.{% endtrans %}
  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}Federated Query Processing{{ se }} across multiple KGs, allowing users to pose {{ ss }}natural language questions{{ se }} that are transformed into SPARQL and executed over LDM and ORKG.{% endtrans %}
  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}Dataset Comparison and Visualization{{ se }}, offering tools to analyze and contrast RDOs based on shared attributes and research contexts.{% endtrans %}
  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}Live Code Execution{{ se }} via {{ ss }}Jupyter Notebooks{{ se }}, enabling reproducible scientific workflows and interactive data analysis within a secure, containerized environment.{% endtrans %}
  • {% trans ss=ss|safe, se=se|safe %}{{ ss }}Neuro-Symbolic Reasoning{{ se }} for both query answering and metadata expansion, combining symbolic models with LLM-based contextualization to enhance discoverability and usability of RDOs.{% endtrans %}
