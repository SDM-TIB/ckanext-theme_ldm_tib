    {{ _("APIs offered by the Leibniz Data Manager") }}

    {{ _("The Leibniz Data Manager (LDM) is an open-source and free web-based application for Research Data Management (RDM). To facilitate integration with external tools and workflows, the LDM offers a series of APIs that fulfil various data management purposes.") }}

    {{ _("The APIs offered can be applied in the following areas:") }}

    • {{ _("Service for Data Comparison") }}: {{ _("This API enables direct side-by-side comparison of CSV datasets. Upload two or more CSV files, join them on a shared key column, and explore the result in a filterable table. Visualisations can be rendered as line, scatter, or bar charts with an optional logarithmic scale.") }}
      • {{ _("Incremental resource loading — start with a single CSV and join additional files one at a time") }}
      • {{ _("Automatic left-join on the first shared column across datasets") }}
      • {{ _("Filterable table with column-level search and pagination (DataTables)") }}
      • {{ _("Interactive charts with selectable series and filtering to currently visible rows (Plotly)") }}
      • {{ _("Available as a Docker container or a local Python application") }}
      {{ _("This API is available on") }} GitHub.
    • {{ _("Service for Jupyter Notebook Execution") }}: {{ _("A containerised, multi-user JupyterHub instance with a unified REST API for notebook management. Designed for integration into external applications that need to spawn temporary Jupyter environments and serve notebooks to end users.") }}
      • {{ _("Configurable pool of guest users for concurrent sessions (e.g. guest0..guestN)") }}
      • {{ _("Automatic cleanup of idle servers with configurable timeouts and kernel lifecycle management") }}
      • {{ _("Per-container resource limits for CPU, memory, and disk") }}
      • {{ _("Admin dashboard for configuring limits and monitoring active sessions") }}
      • {{ _("Unified REST API on a single port for all operations") }}
      {{ _("This API is available on") }} GitHub.
    • {{ _("Service for Knowledge Graph Creation") }}: {{ _("This API transforms heterogeneous data sources into RDF knowledge graphs using SDM-RDFizer executed with RML mappings. RML (RDF Mapping Language) is a declarative language for defining how data elements from sources such as CSV, JSON, or XML correspond to RDF subjects, predicates, and objects. The API allows users to submit datasets and RML mapping rules, automatically execute the transformation process, and output the resulting knowledge graph to a specified folder.") }}
      • {{ _("Supports heterogeneous source formats (CSV, JSON, XML, relational databases)") }}
      • {{ _("Automated RDF triple generation based on RML mapping rules") }}
      • {{ _("Knowledge graph output to a configurable folder") }}
      {{ _("This API is available on") }} GitHub.
    • {{ _("Service for Knowledge Graph Integration") }}: {{ _("This API maps dataset metadata properties to those defined in a mapping template. The purpose of this service is to map dataset metadata to the structure required by the dataset template of the Leibniz Data Manager (LDM), facilitating easier import of datasets into the platform.") }}
      • {{ _("User-defined mapping templates for linking existing metadata properties") }}
      • {{ _("Support for nested metadata structures via iterator configuration") }}
      • {{ _("Generates a structured output file compatible with the LDM dataset template") }}
      {{ _("This API is available on") }} GitHub.
    • {{ _("Service for Knowledge Graph Exploration") }}: {{ _("This API returns metadata about datasets associated with a scientific publication or an author's ORCID. It supports both single-entry lookups and batch processing of multiple DOIs in a single request.") }}
      • {{ _("Retrieve dataset metadata by DOI — individually or as a batch of multiple DOIs") }}
      • {{ _("Retrieve dataset metadata by an author's ORCID") }}
      • {{ _("Retrieve datasets citing an author's work, identified by ORCID") }}
      • {{ _("Supports both GET and POST requests") }}
      {{ _("This API is available on") }} GitHub.
